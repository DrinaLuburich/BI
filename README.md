## Big Data con mis palabras
 
**Qué es Big Data:** Tecnología que permite manipular grandes volúmenes de datos para extraer conclusiones valiosas para una empresa.
 
**Un ejemplo que sí es Big Data, y por qué:** Utilizar el histórico de ventas de todos los productos de un almacén para poder predecir ventas futuras en determinados periodos.
 
**Un ejemplo que no es Big Data, y por qué:** Un Excel con una relación de número cliente, nombre cliente y otros datos.
